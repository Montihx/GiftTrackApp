# Отчёт о состоянии Track (перед этапом 10 «Flip»)

Дата: 2026-11-06. Код Flip не писался и не начат; ждём команды «Flip».

## Сделано (Track, ТЗ этапы 2–9 с поправками заказчика)
- **Источники событий:** листинги — MRKT и Portals (`services/market_listings.py`) и маркет Telegram (`services/telegram_market.py`, с контактом продавца); апгрейды — со стороны Telegram (`services/telegram_upgrades.py`, владелец известен); продажи — из блокчейна (скан и поток TonAPI, пока нет другого источника). Блокчейн-листинги и апгрейды выключены (`ONCHAIN_*`).
- **Шина:** Redis Streams, consumer group `g:dispatcher`, `XACK`, повторы, `nft_dlq`, `XAUTOCLAIM`, дедупликация (ТЗ 5.2, 5.4).
- **Доставка:** лимиты 25/с глобально и 1/с, 20/мин на пользователя, сводка «ещё N», 429/403, баны, пауза, тихие часы, подписка (`SUBSCRIPTION_REQUIRED`).
- **Фильтры:** коллекция/модель/фон/символ, флор модели, номер подарка, цена; две галочки «только если можно написать владельцу» (листинги, апгрейды).
- **Алерты:** ссылки только на Telegram, кнопка «Написать владельцу», оценка и «Выпущено» из Telegram, флоры MRKT/Portals.
- **Мини-приложение:** вкладки Лента (сигналы), Витрина, Избранное, Фильтры, Подписка.
- **Подписка:** единая на Track и Flip (49/89/119 $ через CryptoBot), напоминание за 3 дня, `/status`, `/pause`, `/resume`, `/quiet`, `/tz`.
- **Эксплуатация:** админка (`/ban`, `/stats`, `/dlq`, `/broadcast`, `/grant`…), алерты администратору (`services/health_monitor.py`), `/privacy` и `/delete_me`, `scripts/backup.sh`, `scripts/update_server.sh`.
- **Качество:** `pytest` (180 тестов), `compileall`, `mypy` (CI), чистка мёртвого кода (Tonviewer, listener-ton, GraphQL GetGems в listener-market).

- Чистка: режим GetGems в `services/updater.py`, `services/collection_discovery.py`, настройки `GETGEMS_*`.
- Таблицы ТЗ для Flip (`gifts`, `listings`, `offers`, `sales_history`, `notifications`, `fx_rates`), `Decimal` вместо `float` в части сервисов, EN-локализация, тестовое уведомление.
- Нагрузочные и chaos-тесты (ТЗ этап 13).

## Допущения
- Подписка одна на оба режима; вечный доступ и планы `track/flip/bundle` не делаем.
- GRAM — прежний TON, курс 1:1 (`COIN_LABEL`); подтвердить у заказчика.
- Листинги MRKT/Portals идут без контакта продавца; Telegram-маркет — единственный листинговый источник с контактом.
- Неофициальные API (MRKT, Portals) используются без обхода защиты; при отказе источник на паузе.
- `SUBSCRIPTION_REQUIRED=false` по умолчанию, чтобы не отключить владельца; включить после выдачи себе подписки.
